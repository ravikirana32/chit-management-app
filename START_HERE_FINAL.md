# Start Here — Final v51

If you are a beginner, do these in order:

1. Read `BEGINNER_SETUP_DEPLOYMENT_GUIDE.md`.
2. Read `V51_FINAL_PRODUCTION_RELEASE.md`.
3. Read `V50_PRODUCTION_TEST_MATRIX.md`.
4. Run the backend locally.
5. Run the mobile app.
6. Deploy to staging.
7. Execute every applicable test in the matrix.
8. Read `PRODUCTION_GO_LIVE_RUNBOOK.md`.
9. Complete `PRODUCTION_SECURITY_CHECKLIST.md`.
10. Only then deploy production and publish the apps.

The ZIP is cumulative and retains the previous version documents.
