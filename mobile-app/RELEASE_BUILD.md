# Release Build

## Android
- Configure final application ID
- Configure signing credentials
- Configure Play App Signing
- Build internal distribution first
- Validate on physical device
- Then create production AAB

## iOS
- Configure final bundle identifier
- Configure Apple signing
- Configure App Store Connect
- Build internal/TestFlight version
- Validate on physical device
- Then submit production build

## Before store submission
- Privacy policy
- Terms
- Data deletion process
- Support email
- App screenshots
- App icon
- Splash assets
- Production API URL
- Production Socket.IO URL
