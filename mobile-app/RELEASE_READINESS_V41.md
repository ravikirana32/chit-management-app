# Mobile release readiness

Before store submission:
- Configure Android application ID
- Configure iOS bundle identifier
- Configure signing credentials
- Configure FCM/APNs
- Configure API production URL
- Disable development/test endpoints
- Verify financial retry/idempotency behavior
- Test offline states
- Test creator/member role switching
- Test Fixed Draw
- Test Auction
- Test Agent Month
- Test Payment
- Test Payout
- Test notifications
- Verify privacy policy and terms URLs
- Verify app icon/splash
- Run Android release build
- Run iOS release build
