# Mobile E2E Test Checklist

Run against a dedicated backend/test database.

1. Login with test OTP.
2. Restore token after app restart.
3. Creator creates draft chit.
4. Creator invites member.
5. Member accepts invitation.
6. Creator publishes chit.
7. Member sees monthly obligation.
8. Member submits UPI payment.
9. Creator verifies payment.
10. Fixed draw selects eligible winner.
11. Auction member joins auction.
12. Bid is accepted/rejected according to rules.
13. Auction winner is recorded.
14. Payout is created.
15. Creator settles payout.
16. Member sees ledger/payout.
17. Overdue status appears after grace period.
18. Notification is generated.
19. Recovery plan is created.
20. Locked month rejects normal financial mutation.
